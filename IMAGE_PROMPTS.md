# Pujo Pandal — Image Generation Brief

> **Current status:** every slot below already has a hand-made vector illustration (`.svg`, generated by `scripts/generate-illustrations.py`), and the share image `og-image.jpg` is already made from the logo. This brief is only needed to **upgrade** them to richer AI-generated images.
>
> **To swap one in:** save the new image as `.jpg` at the same path (e.g. `public/images/routes/eastern-corridor-grand-themes.jpg`), then change that extension from `.svg` to `.jpg` in `src/lib/images.js` (routes, guides, category and Mahalaya images) or in the pandal's `image_url` in `src/data/pandals.json` (the 5 featured pandals).

**Task:** Generate the 20 images below and save each one at the **exact path** given. Paths are relative to the project root.

**The code is already wired up. Do NOT edit any code.** Each image appears automatically once its file exists. If a file is missing, the site falls back to its red/gold gradient design, so you can add images one at a time.

---

## 1. Rules for every image

**File format**
- Format: **JPG**, quality ~80, sRGB.
- Size: **1600 × 900 px (16:9)**, except the social share image (1200 × 630).
- File weight: **under 300 KB** each. Compress if needed.
- File names: lowercase, exactly as written. Don't rename them.

**Visual style** (keep it consistent across all 20)
- Rich, warm, semi-realistic **digital illustration / painterly style**. It should match the brand logo at `public/logo.png`.
- Brand palette: deep crimson `#820A14`, dark maroon `#3A0212`, festive gold `#E8AE45` / `#FBD596`, warm cream `#FBF4EA`. Accents can be marigold orange and leaf green.
- Warm festive lighting: lamps, diyas, fairy lights, golden glow.
- Subtle Bengali motifs where they fit: alpana patterns, mandala borders, kash phool (white kans grass), dhak drums, marigold garlands.

**Composition**
- Keep the **main subject in the center 60% of the frame**. The site crops images into short wide cards (16:9 down to roughly 3:1) and puts badges on the corners.
- Leave the **bottom 25% calmer and darker**, because white text sits on top of it.

**Must NOT contain**
- ❌ Any text, letters, words, logos or watermarks.
- ❌ Real, identifiable people or celebrity faces. Crowds should be soft, distant or seen from behind.
- ❌ Anything disrespectful to the deity. Show Maa Durga only in a respectful, traditional, fully adorned form, never cropped awkwardly or in a comedic style.
- ❌ Copies of real photos, or claims to show a specific real pandal exactly. These are **illustrative** images, and the site labels them that way.

**Prompt suffix:** add this to the end of every prompt below:

> *Warm festive digital illustration, semi-realistic painterly style, crimson #820A14 and gold #E8AE45 palette, soft golden glow, Bengali Durga Puja atmosphere, centered subject, calm darker lower area, 16:9, high detail, no text, no letters, no logos, no watermark.*
